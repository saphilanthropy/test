# Post ideas

The queue `/linkedin-post` pulls from when it's run without a topic. Add ideas
freely — a one-liner is enough, the agent develops the angle.

**Format:** one bullet per idea. Strike through (`~~like this~~`) when used, and
leave it in place — the history is what stops the agent repeating itself.

**Ordering:** roughly by priority, strongest at the top. The agent takes the top
unused idea unless something further down is clearly more timely.
